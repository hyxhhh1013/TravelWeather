## 一、选题说明与需求分析

### 1.1 选题背景

出行前查看目的地天气是高频刚需。本项目以「多城市出行天气助手」为主题，在 HarmonyOS 上完成实时天气查询与七日预报展示，覆盖课程要求的网络、组件、状态管理与 Navigation 等核心知识点。

> 选题需在班级群登记且不可重复。请确认班级登记主题为「出行天气助手」后再正式提交。

### 1.2 功能需求

1. 展示预设出行城市列表（北京、上海、广州、成都、长沙、杭州）
2. 网络请求 Open-Meteo 获取实时天气与七日预报
3. 首页展示加载中 / 失败 / 空数据 / 成功四种状态
4. 可复用天气卡片组件，支持进入详情
5. 详情页展示七日明细与最高气温柱状图（加分项）
6. Navigation 实现首页 ↔ 详情跳转、城市参数传递与返回栈

### 1.3 非功能需求

- 仅依赖 DevEco Previewer，不依赖真机
- 网络异常可重试，界面反馈明确
- 代码模块分层清晰，便于答辩讲解

## 二、总体设计

### 2.1 技术选型

| 项目 | 选型 |
| --- | --- |
| 开发工具 | DevEco Studio |
| 系统 / SDK | HarmonyOS 5.0.0（API 12） |
| 语言 | ArkTS |
| 状态管理 | 声明式 UI 状态管理 V2（`@ComponentV2`） |
| 路由 | Navigation + NavPathStack（自定义 PageMap，兼容 Previewer） |
| 网络 | `@ohos.net.http` |
| 天气数据 | Open-Meteo Forecast API（免 Key） |

### 2.2 模块结构

```
pages/          页面（Index 路由宿主、HomePage、DetailPage）
components/     可复用组件（WeatherCard、TempChart）
services/       网络服务（WeatherService）
model/          数据模型与天气码映射
common/         城市常量数据
```

### 2.3 页面与路由

1. `Index`：Navigation 根容器，启动后压入 `HomePage`
2. `HomePage`：城市 Grid + 天气 List + 刷新
3. `DetailPage`：接收 `CityInfo` 参数，展示详情与图表

传参方式：`pathStack.pushPathByName('DetailPage', city)`  
返回：系统标题栏返回 / 路由栈 pop

## 三、关键实现

### 3.1 网络交互与状态机

`LoadStatus = 'idle' | 'loading' | 'success' | 'empty' | 'error'`

- 请求前置为 `loading`，展示 `LoadingProgress`
- HTTP 非 200 或解析失败 → `error`，展示错误文案与「重新加载」
- 成功但无预报数组 → `empty`
- 成功渲染天气卡片 / 列表 / 图表

核心请求封装于 `WeatherService.fetchWeather`，使用 `http.createHttp()`，在 `finally` 中 `destroy()`，避免资源泄漏。

### 3.2 自定义组件（V2）

**WeatherCard**

- `@Param`：城市、当前天气、是否显示操作按钮
- `@Event onOpenDetail`：向外抛出「查看详情」事件
- 多处复用：首页选中区、城市列表、详情页头部

**TempChart（加分）**

- `@Param labels / values`：绑定接口返回的日期与最高温
- 按相对高低动态计算柱高，接口刷新后图表同步更新

### 3.3 容器组件使用

| 容器 | 使用位置 |
| --- | --- |
| Row / Column | 标题栏、卡片内部、预报行 |
| Grid | 首页城市选择 |
| List | 全部城市速览 |
| Scroll | 首页与详情长内容滚动 |

### 3.4 Navigation 与 Previewer 兼容说明

系统路由表（`router_map`）在模拟器可用，但 **Previewer 不支持**。本项目采用自定义 `.navDestination(PageMap)`，保证作业要求的「Previewer 可预览」；同时保留 `route_map.json` 便于对照路由名称。

## 六、总结与体会

本项目将课程中的容器布局、自定义组件、状态管理 V2、Navigation 与网络请求整合到一个完整出行场景中。开发过程中重点解决了 Previewer 与系统路由表的兼容问题，并完成了基于真实网络数据的简易柱状图加分项。
