# 提交材料清单

按头歌「项目要求与课程报告」作业准备：

1. **开源 Git 仓库地址**（GitHub / Gitee 等公开可读）
2. **项目文档**：`docs/课程报告-出行天气助手.docx`（或按学院模板微调后的版本）
3. **Git 提交记录截图**：本地执行 `git log --oneline` 后截图上传
4. **演示录屏（可选）**：Previewer 下展示首页加载、跳转详情、返回、图表

## 提交前自检

- [ ] 班级群已登记选题「出行天气助手」，且主题不与同学重复
- [ ] DevEco Previewer 可打开首页并完成跳转
- [ ] 联网环境下天气数据可刷新
- [ ] 仓库已 push，链接可公开访问
- [ ] 报告中姓名学号信息正确

## 建议远程仓库命令

```bash
cd TravelWeather
git remote add origin <你的仓库 HTTPS 地址>
git push -u origin master
```
